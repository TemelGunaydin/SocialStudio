BAŞLANGIÇ REHBERİ

Adım adım hazır ol.

İçerik yardımcını bağla

OpenAI, ürün sayfandan özellik önerileri ve gönderi taslakları hazırlar. ChatGPT aboneliği API kullanımını kapsamaz.

  1. OpenAI API anahtarları sayfasını aç ↗
  2. Kendi hesabında faturalandırmayı etkinleştir, bütçe bildirimlerini ayarla ve yeni bir anahtar oluştur.
  3. Anahtarı aşağıya yapıştır. Kaydetmek API çağrısı yapmaz; çalıştığı henüz doğrulanmış sayılmaz.

Anahtarın yoksa bu adımı atla. Elle taslak hazırlamak ücretsizdir. Ücretli metin/görsel üretimi ayrı düğmelerle başlatılır.

Neyi tanıtmak istiyorsun?

Ürününün, hizmetinin veya uygulamanın sayfasını ekle. URL'den önerileri getir, bilgileri kontrol et, projeyi kaydet.

URL okuma OpenAI'de ücretlenebilir. Sayfa içeriği OpenAI'ye gönderilir; hiçbir şey X'e yayınlanmaz.

X hesabını kendi uygulamanla bağla

Bu adım X tarafında bir kez yapılır. Ortak sunucu veya bize ait bir X uygulaması kullanılmaz; kredi ve yetkiler senin hesabında kalır.

  1. Developer hesabını aç. X Developer Console ↗ üzerinden uygulamanı oluştur veya mevcut uygulamanı aç. İstenirse kullanım açıklaması için aşağıdaki örneği kendi kullanımına göre düzenle.
  2. Kullanıcı yetkilendirmesini etkinleştir. Uygulama ayarlarında User authentication settings / Set up veya Edit bölümünü aç. OAuth 2.0 için Web App (confidential client) seç. Menü adları X sürümüne göre değişebilir.
  3. Callback'i birebir kopyala. Sonuna ek boşluk veya / koyma. Website URL alanına kendi HTTPS ürün siteni gir; aşağıdaki callback ayrı alandır.
  4. Kaydet ve OAuth 2.0 anahtarlarını al. Keys and tokens altında OAuth 2.0 Client ID ve Client Secret değerlerini bul. API Key, API Secret ve Bearer Token bu alanlar için doğru değerler değildir.
  5. Aşağıya kaydet, sonra hesabını yetkilendir. X izin ekranında doğru hesabı kontrol et. Bu adım gönderi yayınlamaz; X hesap okuma çağrısı ücretlenebilir. Güncel fiyatları kontrol et ↗
İzinler ve “Read and write” farkı

OAuth 2.0 yetkileri bağlantı sırasında istenen tweet.read tweet.write users.read media.write offline.access kapsamlarıyla belirlenir. Console'daki OAuth 1.0a “Read and write” ayarı tek başına OAuth 2.0'ı etkinleştirmez. Bu uygulama DM okuma veya otomatik yayın istemez. X resmi uygulama rehberi ↗

Kullanım açıklaması örneği (İngilizce)

Yalnızca gerçek kullanımına uyuyorsa kullan; X şartlarını kendin inceleyip kabul et.

Boş alanlar kayıtlı değeri korur. Bilgileri değiştirmek mevcut X bağlantısını keser; yeniden yetkilendirmen gerekir.

X izin ekranını aç ↗
Bağlanamadım / Client ID görünmüyor
  • Client ID yok: Önce kullanıcı yetkilendirmesini Web App olarak kaydet; sonra Keys and tokens bölümünü yeniden aç.
  • Callback/redirect hatası: Yukarıdaki adresin protokol, port, yol ve son / karakterini birebir karşılaştır. localhost ile 127.0.0.1 farklı adreslerdir.
  • 401 / invalid_client: API Key yerine OAuth 2.0 Client ID ve Client Secret kullan. Aynı X uygulamasına ait olmalılar.
  • 403 / ödeme / erişim: X Console'da API erişimini, hesabın kredisini ve izinleri kontrol et. Ücretsiz erişim garanti değildir.
  • İzinler değişti: Panelden bağlantıyı kesip tekrar bağla. Yanlış X hesabındaysan yetkilendirmeyi iptal et.
